Charlie Lux Home — Frontend Project

A modern, responsive e-commerce frontend for a premium home décor brand. The project focuses on creating an elegant shopping experience with a clean layout, responsive design, product showcases, promotional banners, and interactive sliders.

✨ Features

* Responsive design for desktop, tablet, and mobile devices
* Modern home décor e-commerce interface
* Promotional announcement bar
* Responsive navigation/header
* Hero image carousel with multiple promotional slides
* Product and category sections
* New arrivals product showcase
* Interactive product sliders
* Product cards with pricing and action buttons
* Custom navigation arrows
* Responsive mobile layout
* Custom hover and transition effects
* Optimized image-based product presentation
* Google Fonts integration using Inter

🛠️ Technologies Used

* HTML5 — Website structure and semantic markup
* CSS3 — Styling, layouts, animations, and responsive design
* JavaScript — Interactive functionality
* jQuery — DOM manipulation and slider integration
* Slick Carousel — Hero and product sliders
* Google Fonts — Inter typography

🚀 Getting Started

No build tools or package installation are required.

1. Clone the repository

git clone https://github.com/Dipan-dev/Frontend-Projects.git

2. Open the project

Navigate to the project directory:

cd Frontend-Projects

3. Run the website

Open index.html directly in your browser.

For a better development experience, you can use VS Code Live Server or another local development server.

🔗 External Libraries

This project uses CDN-hosted libraries:

* jQuery
* Slick Carousel
* Google Fonts

These dependencies are loaded directly from their respective CDNs through index.html.
